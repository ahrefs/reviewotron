# Suggested Commands

- `make build` — Build the project with dune
- `make test` — Run all tests with dune runtest
- `make fmt` — Auto-format with ocamlformat (dune fmt --auto-promote)
- `make clean` — Clean build artifacts
- `make clean && make build && make test && make fmt` — Full quality gate
- `dune utop .` — Interactive REPL
- `dune build -w` — Watch mode
